# 실습과제 1
### 인자와 매개변수를 구분하여 설명하시오.
인자는 함수를 호출하는 쪽에서 함수에 전달하는 값이나 변수이다.
매개변수는 호출되는 함수에서 전달받은 인자를 저장하거나 참조하기 위해 선언하는 변수이다.
즉, 인자는 호출하는 함수의 지역변수이고, 매개변수는 호출당하는 함수의 지역변수이다.
###  함수 호출시 자동으로 처리되는 2가지는 무엇인가?
함수가 호출되면 먼저 매개변수가 메모리에 할당된다.
그다음 호출하는 쪽에서 전달한 인자의 값이 매개변수에 복사되어 초기화된다.
=>매개변수 할당, 인자값으로 매개변수 초기화.
###  값에 의한 호출로 다른 함수에서 선언된 변수의 값을 변경할 수 없다. 이유를 설명하라.
값에 의한 호출은 인자의 실제 변수가 전달되는 것이 아니라 인자의 값만 매개변수에 복사되어 전달되는 방식이다. 호출된 함수 안에서 매개변수의 값을 변경해도 원래 함수에 있던 지역변수는 변경되지 않는다.
###  주소에 의한 호출을 사용해야하는 경우를 2가지 이상 설명하라.
주소에 의한 호출은 함수에서 원본 변수의 값을 직접 변경해야 할 때, 함수에서 2개 이상의 값을 결과로 돌려주어야 할 때 사용할 수 있다.
###  인자가 객체인 경우는 어떤 호출방식이 좋은가?이유도 설명하라
주소에의한 호출이 좋다. 크기가 큰 객체를 값에 의한 호출로 전달하면 객체 전체가 복사되기 때문에 복사 생성자가 호출되고, 객체의 크기가 클수록 메모리 사용량과 실행 시간이 증가한다.
### 함수 반환과정에서 자동으로 처리되는 2가지는 무엇인가?
임시변수가 생성되며 반환값으로 초기화된다.
###  함수 반환과정에서 임시변수가 필요한 이유를 설명하라
함수 안에서 선언된 반환값은 지역변수이므로 함수가 종료되면 메모리에서 사라진다.
따라서 함수가 끝난 뒤에도 반환값을 호출한 쪽에서 사용할 수 있도록, 함수가 종료되기 전에 반환값을 임시변수에 저장해 두어야 한다.
이후 함수 호출문은 이 임시변수로 대체되고, 대입 연산이 끝나면 임시변수는 사라진다.
